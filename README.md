# Abyss of the Fallen - 开场关卡 Demo

这是一个使用 Godot 制作的中世纪暗黑风格回合制 RPG 开场关卡原型。

## 关卡目标
玩家操作主角 **莱纳**，在亡者峡谷与污染幼龙战斗。通关后，玩家将通过剧情文本了解：

- 讨伐巨龙的行动导致深渊污染源扩散。
- 黑骑士团全军覆没，仅莱纳生还。
- 灾难背后存在名为 **夜鸦议会** 的组织。
- 莱纳正式踏上追查真相与复仇之路。

## 操作说明
- **斩击**：稳定输出。
- **格挡**：降低下一次受到的伤害。
- **净蚀誓言**：高伤技能，在战斗中触发共鸣后可用。

## 运行方式
1. 使用 Godot 4.x 打开项目根目录。
2. 运行主场景 `res://scenes/IntroLevel.tscn`。
